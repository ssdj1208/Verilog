# Nexys4 五级流水课堂讲解稿

## 1. 开场版

大家现在看到的是我这个 RISC-V CPU 在 Nexys4 DDR 板上的硬件演示。
它不是只把程序跑起来，而是把五级流水的执行过程直接映射到了板载 LED 和数码管上，所以我们可以在实物上观察指令是怎么经过 `IF、ID、EX、MEM、WB` 这五个阶段的。

## 2. 先讲“整体目标”

这次我想证明三件事：

1. 这颗 CPU 不是单周期，而是真正的五级流水
2. 它不仅能连续跑，还能看到流水里的停顿和冲刷
3. 这些现象不是口头描述，而是能在 FPGA 板上直接观察到

## 3. 板上资源说明

我这里用了三类资源：

- LED：显示五级当前是否有效，以及 stall、flush 这类事件
- 数码管：显示所选流水级的完整 PC 或完整指令编码
- 按键：实现运行、暂停、单步和翻页

这个设计里：

- `btnU` 控制运行和暂停
- `btnL` 每按一次推进 1 个 CPU 周期
- `btnR` 切换 PC 页和指令页
- `btnD` 切换慢跑速度
- `btnC` 负责复位

## 4. 进入演示模式

我先把 `sw[15]` 置成 `1`，再按复位。
这样系统不会进入原来的串口 shell，而是进入专门为课堂展示准备的一段短程序。

这段程序会循环触发几种典型流水现象：

- 顺序执行
- 前递
- `load-use stall`
- `div` 带来的多周期停顿
- 分支跳转带来的 `flush`

## 5. 第一段演示词：流水在流动

现在我先让它慢速运行。
大家可以用 `sw[2:0]` 选择 `F、D、E、M、W` 中的任一级。
数码管显示该级完整 PC，LED 前五位同时说明五级当前是否有效。

这就是五级流水最核心的特征：
不是一条指令做完再做下一条，而是多条指令重叠执行。

## 6. 第二段演示词：单步推进

接下来我把它暂停，然后按单步。
现在每按一次，就只推进 1 个 CPU 周期。

这样我们就能看到：

- 一条新指令先进入 IF
- 下一拍进入 ID
- 再下一拍进入 EX
- 之后进入 MEM
- 最后在 WB 完成写回

如果连续按几次并依次选择各级，就能把一条指令从取指一直跟到写回。

## 7. 第三段演示词：为什么会停

下面重点看 LED。

如果 `load-use stall` 亮起，就说明当前有一条 `lw` 指令刚把数据从存储器拿回来，紧接着下一条指令就要用这个结果。
因为结果还没来得及稳定进入下一阶段，所以流水线必须停一个周期。

如果 `mul/div stall` 亮起，就说明我这里的 `div` 不是单周期完成的。
它会在 EX 阶段持续若干拍，因此后面的流水也要等它。

这两个例子说明：
流水线并不是永远理想前进，它会因为真实的数据相关和运算延迟产生停顿。

## 8. 第四段演示词：为什么会冲刷

再往后看，当 `branch flush` 亮起时，说明分支方向已经在 EX 阶段判定出来了。
但在这之前，前端可能已经顺着预测路径多取了几条指令。

如果发现路径不对，就必须把错误路径上的指令清掉，也就是 `flush`。
这时候你会看到前面几级的显示发生明显跳变。

所以这里展示的是：

- 流水为什么能提高吞吐
- 以及它为此必须处理的控制相关问题

## 9. 第五段演示词：查看某一级的完整 PC

现在数码管处于 PC 页，显示我选中的某一级的完整 PC。
按 `btnR` 后会切到指令页，显示同一级的完整 32 位指令编码。

我用 `sw[2:0]` 选择 IF、ID、EX、MEM 或 WB，
再按单步，就能观察这个阶段里的 PC 怎样随时钟推进变化。

这个页面更适合回答老师的一个常见问题：
“你说这是五级流水，那具体某一级现在手里是哪条指令？”

## 10. 收尾版

所以这套演示最终说明的是：

1. 这颗 CPU 已经具备完整的五级流水结构
2. 流水中的正常流动、停顿和冲刷都能在实板上观测
3. 它不是只有软件输出结果，而是把微结构行为真正映射到了硬件界面

如果老师希望，我还可以再切回正常模式，进入原来的串口 shell，继续展示 `perf`、`cache` 和其他 SoC 功能。

## 11. 简短问答备稿

### Q1：为什么不用串口直接打印流水状态？

因为串口更适合结果输出，不适合拍级观察。
板载数码管和 LED 更适合实时、低延迟地看流水级变化。

### Q2：为什么演示程序是专门写的，不直接跑完整系统？

完整系统现象太复杂，不利于课堂讲解。
专用短程序能稳定重复触发前递、stall 和 flush，更适合证明五级流水本身。

### Q3：为什么数码管一次只显示一个流水级？

完整 PC 和指令都需要 8 个十六进制数码位。五级整体有效状态由 LED 同时展示，数码管则用于精确观察当前选择的一级。
